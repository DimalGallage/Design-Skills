# Design-Skills

- **[Web Design Guide: The Seven Categories of Modern Web Design](./web-design-guide/README.md):** a research-based classification of the world's websites into seven style categories (Product-Led Tech, Institutional Trust, Editorial, Quiet Luxury, Organic & Human, Bold Expressive, Premium Product Minimalism / "Apple-like") plus an Immersive layer. Each has its use cases, traits and a complete build guide. Also usable as a Claude skill via [`SKILL.md`](./web-design-guide/SKILL.md).
